# IdeaFlow Hub — Demo

This repository hosts the **IdeaFlow Hub Upgrade 66** browser-based innovation management prototype.

## Launch

Open the deployed site, or open `index.html` directly in a browser.

The demo includes a public homepage, idea-giver experience, and role-specific innovation team workspaces, plus five fictional sample projects (can be hidden in Settings). The sample decisions, comments, people and outcomes are illustrative.

## Important

This version uses **browser-local storage** and **simulated sign-in**. It is not a secure multi-user system and should **not** be used for confidential organisational information or real approvals.

Data entered in one browser does not automatically sync to other devices. Export backups from the app's data/recovery settings. A browser-origin change may require importing an existing backup.
